Love at First Shade: Makeup API Project - June, 2026
I aimed to create an app that would help users search for makeup products based on brand, product type, and maximum price. The practical problem I wanted to solve was the difficulty of sorting through large amounts of beauty products online, as there are so many different websites with many different brand types. I thought that it would be convenient to have a program which organized information from a Makeup API to make it much more feasible for the users to find specific beauty products. My project initially started as a simple API search tool, but I quickly found myself adding more features, such as product cards, images, pagination, and even a shopping cart.
